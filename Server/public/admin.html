AGENT POLICY

Agent 连接与无响应恢复

Agent 通过常驻 WebSocket 接收任务通知；这里仅设置队列超时和游戏恢复策略。

任务通知与恢复

Agent 在线时由 Workers 通过 WebSocket 推送新命令通知；命令仍先写入持久队列，连接重建后会自动检查队列。

定时任务仍由后台调度器按配置时区入队；入队后会立即尝试唤醒在线 Agent。接取超时仅影响队列任务的超时处理。
