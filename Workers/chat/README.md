# 营地助手互动中心

本目录基于同级 `yume-chat` 2.10.1 的聊天核心和 Vue 界面集成，保留其许可证。独立项目不受修改。构建入口为 `npm --prefix Workers run chat:build`；`dev`、`deploy` 和 `deploy:dry` 会自动构建聊天资源及本地 Vditor 运行时。构建产物位于 `Workers/public/chat/`，不提交生成文件。

## 访问与身份

- 首页功能顺序为营地公告、营地群资料、身份识别码、互动中心、日常投票等。互动中心使用当前页面跳转到 `/chat/`，桌面和手机导航均提供返回首页入口。
- 识别码登录签发独立的 HttpOnly、SameSite=Strict Cookie。D1 只保存随机令牌的 HMAC，不保存明文令牌或密码。网站投票和资料操作也可验证此 Cookie；旧浏览器凭据在成功刷新后迁移为无密码缓存。
- 每个聊天请求、附件请求和实时消息都会验证识别码。停用、到期、注销、重置密码、退出登录后无法继续访问。延期审批期间的额外投票资格不授予聊天访问权。空闲实时连接每分钟重新检查一次，失效后关闭。
- 识别码号码禁止更换，前台和后台更换入口及 API 已删除。数据库同时保护号码和密文不被修改。聊天用户按不可变识别码记录关联，显示名称与 @ 名称同步使用玩家名称，头像同步使用识别码头像。
- 聊天不提供单独登录、OIDC、个人设置、退出登录、用户资料编辑、Telegram 或跨实例群组联动。退出登录统一通过首页身份识别码卡片操作。每次验证聊天会话都会从识别码刷新玩家名称与 @ 名称，自动修正聊天资料中的旧名称。
- 群成员与通讯录只显示有效识别码。新增、停用、注销、资料变更通过已认证目录 WebSocket 推送；到期边界通过 Alarm 刷新，另有每30秒校验及重连恢复。在线状态依据有效聊天连接，支持多设备；75秒无心跳或识别码失效会移除在线状态。复用现有 ChatInbox 绑定，无需新建数据库表或 DO。
- 已登录身份卡片支持修改密码：先验证旧密码，签发与当前会话及密码绑定的5分钟验证凭据；新密码成功保存后撤销所有设备会话并清除当前 Cookie，要求重新登录。
- 会话卡片第一行显示群名或玩家名称，第二行显示最新未删除消息的摘要，附件显示对应类型或文件名；消息仅在验证房间成员权限后解密投影。实时私聊通知会立即补齐新会话，重连后重新同步，并保护正在读取快照期间收到的消息和已读状态。本项不修改数据库结构。
- 默认群使用稳定内部标识 `general`，显示名称随语言变化：全体成员群、全體成員群、All members、全メンバーグループ、Tous les membres。
- 聊天页面独立使用 `localStorage` 中的 `lang` / `yume-theme` 偏好，不再读写跨子域 Cookie。支持自动、简繁中文、英语、法语和日语及自动/浅色/深色主题。

## 后台

`/admin#chat` 集成会话、消息、聊天文件及聊天运行参数管理，不提供 `/chat/admin`。该模块没有用户管理、跨实例绑定或 Site setting（名称/图标）功能。

识别码用户始终是普通聊天用户，数据库禁止其获得全站管理员标记。聊天页没有管理入口，`/chat/admin` 及其子路径返回 404。只有通过 OIDC 或 Key 登录营地系统后台后，才能进入聊天管理。

查看包含私聊在内的全站会话和文件必须具有 `admin:chat`（或系统最高）权限；Demo 和其他模块权限不允许读取。不提供访问日志功能，不记录聊天管理访问事件。修改沿用营地后台 Cookie 和 CSRF 验证。

运行参数保存在 D1 的 `settings.chat_policy`，迁移写入默认配置。后台可修改并恢复默认值，无需修改 Wrangler：

| 参数 | 默认值 |
| --- | --- |
| MESSAGE_RETENTION_DAYS | 7 天 |
| SOFT_DELETE_RETENTION_DAYS | 60 天 |
| MAX_FILE_SIZE | 20971520 字节（20 MiB） |
| ORPHAN_UPLOAD_RETENTION_DAYS | 1 天 |
| ALLOWED_FILE_TYPES | image/,video/,audio/,application/pdf,text/plain |

上传上限允许 1 KiB 至 50 GiB（后台按 MB 输入，1 MB = 1048576 字节），默认仍为 20 MiB。可设置 100、500、1024 等值。参数每次请求从后台配置读取；有界限的资源清理任务每 10 分钟执行。缩短保留时间会在下次清理时删除到期资源。

超过 8 MiB 的附件自动使用 8 MiB 分块，经 Worker 的现有 `FILES` R2 绑定写入，不需要 S3 Access Key，也不需要公开桶或增加 CORS。每个请求均小于 Cloudflare 单请求上传限制，因此支持超过 100 MB 的文件；这属于绑定分块上传，不是浏览器直接访问 R2。每块以 AES-256-GCM 独立认证加密，绑定对象键、分块序号和文件长度；服务端持有密钥，不属于端到端加密。未完成的上传 24 小时后按预算中止并清理，上传失败会主动取消。

大附件按流读取和分块解密，支持 HTTP 单区间 Range（视频拖动、断点下载）；旧附件仍可读取。图片点击放大；视频点击打开播放器，支持播放、暂停、进度拖动，按原比例适配窗口。文件能否解码取决于浏览器支持的媒体编码。

消息气泡、待发送区、引用和置顶摘要使用本地化的图片／视频／音频／文件类型标签，下载时保留原始文件名。媒体预览使用首页玻璃材质和主题色，工具栏、媒体区与播放器控制栏分别布局；桌面、手机与横屏均按可视高度适配，视频进度条始终显示。所有附件上传立即显示可取消的百分比弹窗，小文件与分块均按浏览器实际发送字节更新，上传后保留处理阶段直至服务端确认完成。

部署前须应用 `0046_chat_multipart_upload.sql`。所有附件的上传、分块合并、读取和删除都使用 `STORAGE_PREFIX`；配置 `lifeafter` 时物理路径为 `lifeafter/chat/<用户ID>/<文件ID>`，接口和消息只保存逻辑键。更改前缀前须迁移已有对象。

## 部署

1. 安装 Workers 依赖并运行 `npm --prefix Workers run check`。
2. 部署前通过 `wrangler d1 migrations apply` 应用未执行迁移。`0042_identity_chat.sql` 已恢复为 Build 27157 的原始内容，不应重跑或修改。新增 `0043_retire_chat_access_log.sql` 只删除废弃的 `chat_admin_audit` 表及其中日志，保留识别码、聊天消息、文件登记和配置。尚未应用 0042 的库会依次执行 0042、0043；已应用 0042 的库只执行 0043，短暂版本中该表不存在也可升级。上述命令不会导入本地测试数据。本轮未操作远程数据库。
3. Wrangler 已配置 `FILES` → `yume-oss`、`CHANNEL_ROOM` → `ChatRoom`、`USER_INBOX` → `ChatInbox`，以及 `v3-chat` Durable Object 迁移。使用现有 D1 数据库，无需新建聊天数据库或 KV。
4. `STORAGE_PREFIX` 是唯一的聊天存储路径部署参数，默认为 `lifeafter`，不要加开头斜线。头像写入 `lifeafter/avatars/…`；聊天附件及群头像写入 `lifeafter/chat/…`。历史文件使用原键读取；更改前缀时应同步迁移已有对象。
5. 消息和聊天附件使用 AES-GCM 静态加密，默认由现有 `SESSION_SECRET` 派生专用密钥。可以通过 `EDGECHAT_ENCRYPTION_KEYRING` Secret 提供独立密钥环。不要移除仍被历史消息或附件使用的密钥。此功能不属于端到端加密，授权营地管理员可通过管理模块查看内容。

头像接受不超过 5 MiB 的 PNG/JPEG/WebP，并验证文件签名；界面提供裁剪、拖动和缩放，将图片输出为 512×512。头像经登录接口读取；聊天文件继续按房间成员和文件所有者授权，并在 R2 加密存储。部署绑定及存储前缀保留在 Wrangler，运行参数默认值不放在 Wrangler。


## 旧库升级命令

在 `Workers` 目录执行，先导出备份，再查看和应用未执行的迁移，最后部署 Worker：

```sh
npx wrangler d1 export yume-camp-assistant --remote --config wrangler.jsonc --output=/tmp/yume-camp-assistant-before-0043.sql
npx wrangler d1 migrations list yume-camp-assistant --remote --config wrangler.jsonc
npx wrangler d1 migrations apply yume-camp-assistant --remote --config wrangler.jsonc
npm run deploy
```

迁移进度由 D1 的 `d1_migrations` 表记录。不要清空数据库、删除迁移记录，或使用 `d1 execute --file migrations/0042_identity_chat.sql` 强制重跑。已发布迁移保持不变；后续表结构变更使用下一个编号的新迁移。0043 会删除旧访问日志，若需留档请保留上述备份。

## Build 27171：撤回与实时同步

部署前先通过上述 D1 migrations apply 流程应用 `0045_message_recall.sql`。
群聊和私聊支持本人发送后 120 秒内撤回；菜单和服务端都会校验作者与时限。
撤回保留原始数据库内容，后台显示「已撤回」标记；普通用户仅收到撤回占位，
原文不会继续出现在引用、会话预览或其他成员的附件访问中。

撤回不清理 R2 附件，后台仍可查看原文件。管理员删除消息或消息到期后，清理无其他有效引用的 R2 附件及文件索引；失败进入现有重试队列。被其他有效消息（含未到期撤回消息）、用户头像或群头像引用的文件保留至最后一个引用移除。后台仍保留消息内容、文件名和撤回/删除标记，已清理的附件不再提供下载。
`POST /chat/api/messages/recall` 接收 `kind`、`roomId`、`messageId`。
删除和撤回会同时通知房间与个人收件箱；断线重连通过消息事件游标补同步，保留滚动位置和输入草稿。
后台成员名单读取当前有效身份，并通过实时更新及可见页面定时补查原位刷新。

Web Push 覆盖 public、private、dm 三种会话类型。系统推送不依赖页面状态，也不因前台状态缓存而被跳过。
iOS 需支持 Web Push 的系统版本及添加到主屏幕的 Web App，并由用户操作授予通知权限；
普通 iOS 浏览器标签页不提供同样的后台推送能力。

互动中心的日语、法语菜单、语音、通知与会话操作均有本地翻译；富文本编辑器使用对应的
简体中文、繁体中文、英语、法语或日语工具栏，并在切换语言时保留草稿后更新。
网页通知卡片固定为 104px 高，名称和正文超出空间时省略；系统推送只携带限长的消息概览。
撤回气泡的时间戳独占一行，与提示保持 6px 间隔。

互动中心前台消息、会话日期和后台消息／附件列表统一使用基础设置中的 `campConfig.timezone`。数据库未带时区的 D1 时间按 UTC 解析，显示时再转换；不采用设备的本地时区。消息右下角为两行 `YYYY/MM/DD` 和 `HH:MM:SS (UTC+8)`；整数偏移省略分钟，非整数偏移保留为 `UTC+05:30`。首页配置更新会直接重绘已有时间文字，后台也会从聊天接口读取最新配置，保留卡片与滚动位置。
