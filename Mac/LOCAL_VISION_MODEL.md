# 本地 2–3B 视觉模型接入建议

## 结论

当前 Mac Studio（M1 Max、32 GB 统一内存）使用 DeepSeek-VL 7B Chat 的 4-bit
视觉语言模型 `mlx-community/deepseek-vl-7b-chat-4bit`，通过 MLX-VLM 在 Apple
Silicon 上本地推理。模型仓库约 4.2 GB，实际延迟和峰值内存需要用本项目截图另行
基准测试，不能只依据参数量推定。

## 推荐职责

模型只作为只读 `VisionAdvisor`：

- 把当前截图归类为已知页面、未知弹窗、加载中、游戏 HUD 或错误页；
- 为 OCR 结果补充上下文，例如判断同名文字属于按钮还是公告内容；
- 在寻路或活动界面改版后提供恢复建议。

模型不输出或执行任何动作、坐标、点击或按键，也不决定以下动作：

- 提交科技、修改日程；
- 踢出队员或营地成员；
- 最终指纹确认；
- 发送聊天消息；
- 关闭游戏或 MuMu 容器。

## 执行门槛

1. 截图先由现有 OCR 和页面规则判断；只有无法归类时才调用模型。
2. 输入为当前瞬时截图、OCR 文本、允许动作枚举和期望页面，不发送历史凭据。
3. 输出必须符合固定 JSON Schema：`state`、`action`、`confidence`、`evidence`。
4. 模型结论只写入诊断日志；置信度和连续帧次数都不能授予执行权限。
5. OCR 或页面签名没有明确匹配时停止后续坐标流程，不连续猜测。
6. 涉及破坏性操作时，最终操作仍走现有精确姓名、固定流程
   和后台确认标记。
7. 推理服务仅监听 `127.0.0.1`，不得暴露到 Cloudflare Tunnel 或公网。

## 当前实装

- 模型：`mlx-community/deepseek-vl-7b-chat-4bit`（DeepSeek-VL 7B Chat）；
- 服务：MLX-VLM OpenAI 兼容接口，固定监听 `127.0.0.1:8092`；
- 生命周期：每次本地任务按需启动，任务结束或中断后停止；
- 状态：默认 `enabled: true`，随本地任务按需启动；
- 模式：固定 `shadow`；模型只返回页面分类和证据，归一化后的动作永远为 `wait`；
- 已开放动作：无；登录、公告、宣传页、地图与 HUD 均必须由 OCR 或确定性页面签名
  明确确认；
- 截图：每次模型调用使用独立瞬时截图，响应或异常后立即删除；
- 故障降级：模型未安装、启动失败、超时或 JSON 不合规时，任务继续走 OCR 与既有
  确定性规则。

控制入口为 `scripts/manage-local-agent.sh`；单独管理模型可执行
`scripts/local-model.sh`。所有模型运行文件位于 `.local-model/` 并已排除出 Git。

## 后续扩展顺序

1. 离线收集并脱敏一批正常 HUD、宣传页、语音邀请、队伍页、地图页和故障页截图。
2. 选择新的本地视觉模型后仍以 `shadow` 模式做只记录、不点击的基准比较。
3. 登录、地图和 HUD 阶段补齐确定性页面签名；模型不得成为执行授权条件。
4. 科技、日程、寻路和踢人保持确定性实现。
